## Your Core Transformation

**I help underground artists and micro-label founders go from *self-releasing on Bandcamp with no distribution* to *running a distributable, licensable, editorially-curated catalog* — using The OCD Method (Obsession → Curation → Distribution).**

The OCD Method is a three-phase operating system:

1. **Obsession** — Define a non-negotiable sonic and visual thesis narrow enough to reject 95% of inbound work.
2. **Curation** — Run a 14-day submissions review loop with a written rejection language and a public roster tier ("Elite Force" model).
3. **Distribution** — Package each release into a four-tier licensing sheet (personal, indie, commercial, exclusive) so revenue exists before streaming pays out.

The method is proprietary because it is *literally* the pipeline running on ocdrecords.com — the buyer receives the machine, not the theory.

## Winning Product Structure

### Name

Proprietary mechanism named on the box: *"The OCD Method: Obsession → Curation → Distribution."* Every asset inside is tagged to one of the three phases so buyers can't confuse it with a generic bundle.

### Contents

**Phase 1 — Obsession Kit**
- One-page "Sonic Thesis" worksheet (the same doc used to reject a submission in <30 seconds).

**Phase 2 — Curation Kit**

**Phase 3 — Distribution Kit**
- Four-tier licensing sheet (personal / indie / commercial / exclusive) with pricing anchors and contract templates — the same tiering shipped on `licensing.html`.
- Studio & Engineer Booking template (from `studios.html`) — a plug-and-play block for labels that want a service-revenue tier before their catalog scales.

**Bonus (upsell tier)**
