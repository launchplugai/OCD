# OCD Records — Productize Yourself Blueprint

> Design brief: convert OCD Records' internal expertise into a system that sells at 3am with no founder online.
> Reference lenses: Naval (permissionless leverage), Dan Koe (one-person scalable IP), Hormozi (grand-slam offer + distribution match).

---

## Read of the current business

OCD Records today runs three revenue lines, and **all three require founder presence**:

| Line | Current form | Founder-time per $1 |
|---|---|---|
| A&R / releases | Submissions reviewed manually via `submit.html` | High |
| Studios | Day rate + per-track mastering (`studios.html`) | Very high |
| Sync licensing | Custom quotes per project (`licensing.html`) | High |

Every dollar today is bottlenecked by the ears in the room. That is exactly what the Productize test rejects. The unlock is not a fourth service — it is packaging the *judgement* that runs A&R and mastering into an asset that ships itself.

**I help obsessive bedroom producers go from "unreleaseable demo" to "signal-locked, label-grade master" using the OCD Signal Chain™ — the same seven-stage obsession protocol OCD Records applies internally before a track is cleared for release.**

## Winning Product Structure

### Name
**OCD Signal Chain™: The Obsession Protocol for Releasable Sound**

The proprietary mechanism is the *Signal Chain* — a named seven-stage loop (below). "Signal Chain" is already the vocabulary on `studios.html`; the product borrows the brand's existing language so it reads as an extension of the label, not a side-hustle course.

### Contents

1. **The 7-Stage Obsession Loop** (framework core)
   1. Identity Capture — diagnose the sonic fingerprint you already have but can't name
   2. Reference Triangulation — pick three impossible-to-copy references, extract the invariants
   3. Arrangement Skeleton — the 8-bar test that predicts a full-track outcome
   4. Frequency Lock — the mix criteria OCD masters against (targets in the rubric)
   5. Translation Pass — the four-system check (studio / car / phone / earbuds)
   6. Master Discipline — LUFS + dynamic-range + tonal targets by format
   7. Release Ritual — the 21-day pre-drop checklist (assets, submissions, pitch scripts)
2. **Signal Lock Rubric** — a scored, fillable checklist. Producer self-grades. Anything below 80/100 doesn't ship.
3. **Ableton + Logic templates** — pre-routed session with the OCD bus chain (analog-summing emulation, mid-side EQ, translation monitoring).
4. **50 Pattern Kits** — stem-ready drum, synth, texture beds tagged to Signal Chain stages.
5. **Rejection-to-Release Case Studies** — three teardowns of tracks that failed Signal Lock, what changed, what shipped.
6. **Submission Pitch Scripts** — the exact wording that reads as label-native, not a demo blast.

### Delivery mechanism (zero live time)

- Hosted on Gumroad or Lemon Squeezy (tax + delivery handled; instant download on purchase)
- Buyer enters the OCD email sequence: 7 emails over 14 days, each unlocking one stage of the Loop
- Discord auto-invite (self-serve, no moderation contract) — social proof, not support
- Updates pushed via Gumroad "new version" notifications — buyers get every future revision free

### What makes it irreplaceable

- **The rubric is proprietary** — the Signal Lock scoring thresholds are OCD's actual internal A&R cutoffs. No other product ships the label's real mastering targets as a self-grade tool.
- **Distribution moat** — the product is fed by the label's own rejection stream (see below). Competitors can build a playbook; they cannot build the funnel.
- **Reverse-consequence pricing** — the buyer can pitch OCD Records after using it. The product is a qualifier, not a substitute — it enhances the label, so the label promotes it without cannibalising.

### Price point

**$147 one-time.**

Rationale:
- Above impulse ($27–$47 sample packs) — signals seriousness, filters tire-kickers
- Below course ceiling ($297–$497) — no cohort, no live calls, no coaching-tier expectation to defend
- Prosumer producers already spend $200+/year on plugins; this is one plugin's price for a system, not a preset
- Margin math: Gumroad ~5% + Stripe ~3% = ~$12 fees, delivery near zero → 91–92% net

Optional $47 "Frequency Lock lite" downsell for anyone who abandons at checkout.

## Distribution Channel (matches existing platform — no cold start)

**The `submit.html` rejection funnel.**

Today: producers submit, most get silently rejected. That's 100% of a warm, self-qualified, in-market audience wasted.

Tomorrow: every submission gets an auto-response within 48 hours. Two tiers:

- **Signed / shortlisted** → normal A&R workflow
- **Not yet** → templated response: *"Your submission didn't clear Signal Lock this round. Here's the exact rubric we scored you against — and the protocol we use internally to get tracks to release-grade. Producers who ship a Signal-Locked track are invited to re-submit."* Link to the Playbook landing page.

Why this beats any other channel:
- Audience is already qualified — they submitted, they care, they were rejected with a reason
- Zero new-channel learning curve — uses infrastructure the site already has
- Feedback loop feeds A&R — Playbook buyers who nail Signal Lock become the next signing pool, so the funnel improves the label's roster over time
- Compliant with the brand — the rejection letter *adds value* where today it adds silence

Secondary channels (once the primary works): release-note footers, artist-page bios linking "How we found this artist" → Playbook, licensing-inquiry follow-ups.

## Week 1 Build Roadmap

1. **Days 1–2 — Codify the framework.** Write the 7-Stage Obsession Loop as a single document with the exact rubric thresholds (LUFS targets, dynamic-range floor, tonal-balance tolerance, translation checklist). This is the artefact everything else copies from. Nothing ships until this exists.
2. **Days 3–4 — Ship the rejection auto-response.** Wire `submit.html` submissions to send a two-tier auto-reply (approved / not-yet). The *not-yet* email links to a placeholder `/playbook.html` landing page with a waitlist opt-in. This starts collecting the audience *before* the product exists.
3. **Days 5–7 — Stand up the Gumroad listing + landing page in OCD's design system.** Reuse `licensing.html` layout as the template (same crimson/electric-blue palette, JetBrains Mono / Archivo / Manrope stack). Offer a 3-page lead-magnet PDF (Stage 1 of the Loop) for email capture. Set price at $147 with the $47 downsell configured. Manual promo code for the first 25 waitlist buyers ($97 founder tier) to drive testimonials for public launch in week 3.

## What this blueprint does *not* include (deliberately)

- **No cohort course, no live coaching, no "1:1 mastering audit" tier.** All fail the Productize test.
- **No new social platform.** The brief forbids starting from zero — every distribution move above rides existing OCD infrastructure.
- **No "community" as the flagship.** OCD Circle can exist later as retention, not acquisition — but only after the Playbook proves the funnel converts.
