## Winning Product Structure

### Name
**Neural Precision Pack: The Obsession-to-Release Stack**
(Anchored to the proprietary mechanism — the **Neural Precision Framework™**.)

### Contents
1. **NPF Playbook (PDF, ~40pp)** — the 10-step framework: Capture → Compress → Carve → Color → Conform → Calibrate → Compare → Commit → Clear → Catalog.
2. **200+ stems & one-shots** pulled from the catalog (Entropy 001, Static Void, Resonance, Lithium Path, Aftermath) — pre-cleared for derivative use.
3. **DAW Templates** — Ableton, Logic, FL Studio sessions wired to the NPF signal chain.
4. **Mastering Chain Presets** — Pro-Q, OTT, Soothe, Limiter chain in `.fxp` / Ableton rack format, tuned per genre lane (Electronic/Ambient, Cinematic, Dark Techno, Avant-Garde).
5. **Reference Track Teardowns** — 5 annotated mix breakdowns (waveform + spectrum screenshots + decision log) of OCD catalog tracks.
6. **A&R Submission Checklist** — the exact rubric the label uses on inbound demos at `submit.html`. Pass the checklist → fast-track review.
7. **Discord access (read/listen-only tier)** — drops, future-pack discounts, alumni gallery. No live presence required from operator.

### Delivery (no live presence)
- **Storefront:** Gumroad (or Lemon Squeezy) listing.
- **Auto-delivery:** ZIP + signed download link emailed instantly on Stripe checkout.
- **Onboarding:** 7-email evergreen sequence (ConvertKit/Resend) that walks buyers through the NPF.
- **Discord auto-invite:** webhook on purchase; role assigned automatically.
- **Site integration:** `index.html` hero secondary CTA + new "Buy the Pack" module on `submit.html` shown to rejected demos ("Didn't sign? Build it yourself.").

### Price Point
**$97 founder price (first 100 buyers) → $147 standard.**

Rationale: well above impulse-tier ($27–$47 sample packs) to signal label-grade authority and protect margin; well below mix-engineer ($500–$2,000) and label-deal alternatives, so it stays an obvious yes for serious producers. At 95%+ digital margin, even 50 sales/month at $97 = ~$4,600 MRR with zero operator hours after launch.

### What makes it irreplaceable
- **The NPF is named, trademarked, and only documented inside the pack.** Competing sample packs sell sounds; this sells a *decision system* nobody else has.
- **Stems are pulled from real OCD catalog releases** — not generic library samples. Provenance > production value.
- **The A&R rubric is the same one used by OCD's submission pipeline.** Buyers aren't getting a course — they're getting the test answers.

## Distribution Channel (matches existing platform)

**OCD Records' submit-to-pack funnel.** Every demo submitted via `submit.html` already self-identifies as the perfect ICP — an obsessed producer reaching for a label. Two zero-friction touchpoints:

1. **Rejection email upgrade:** automated reply to non-signed demos includes a one-line CTA: *"You were 2 steps off the NPF rubric. Here's the rubric — and the stack we used to write it."* → Pack landing page.
2. **Site-native placement:** Hero secondary CTA on `index.html` + post-submission thank-you page.

This uses an existing high-intent inbound channel rather than starting from zero on TikTok / newsletters / paid ads.
