## Winning Product Structure

### Name
**The Artifact Kit: The Obsession-to-Artifact Protocol™**

### Contents (what's inside)
1. **The Protocol PDF (40 pages)** — the named framework
   - Stage 1: **Capture** — how to recognize an obsession worth committing to (3-question filter)
   - Stage 2: **Compress** — the 90-minute session structure that turns 8 hours of noodling into 1 useable stem
   - Stage 3: **Encode** — neural precision pass: which AI tools to use at which stage, with prompt templates (Suno/Udio/Riffusion/iZotope/Splice AI)
   - Stage 4: **Transmit** — the OCD release checklist (masters, art, metadata, story, drop sequence)
2. **The Template Pack** — Ableton + Logic + FL project templates pre-routed for the protocol
3. **The Prompt Library** — 50 vetted AI prompts (mastering, art direction, artist bio, release one-pager)
4. **8 Annotated Reference Masters** — actual OCD-roster tracks with the protocol stages marked on the timeline (.wav + annotated PDF)
5. **The Identity Worksheet** — fills in artist name, manifesto, visual palette, and a release-ready bio in one sitting
6. **Lifetime updates** — quarterly drops added to the same Gumroad/Lemon Squeezy file

### Delivery (how it reaches buyers without you)
- **Storefront:** Lemon Squeezy or Gumroad — auto-delivers ZIP on Stripe success
- **Hosted on:** `ocdrecords.com/kit` (new static page, same Tailwind shell as the existing site)
- **Order bump:** "+$29 — Add the Transmission membership first month"
- **Post-purchase:** automated 7-email sequence (ConvertKit/Beehiiv) that walks them stage-by-stage so refund rate stays under 3%

### What makes it irreplaceable
- The framework is **named, sequenced, and visualizable** — buyers can say "I'm on Stage 3" the way devs say "I'm on sprint 2"
- The reference masters are **proprietary** — no competitor has OCD's roster
- The kit is the **only on-ramp to the OCD submission portal** (gives the submit funnel a paid tier of vetted demos, which feeds A&R)

### Price point
**$149 one-time.** Rationale:
- Below the $200 "course" psychological wall — feels like a tool, not a school
- Above the $49 "PDF" floor — signals it's the real protocol, not a Notion template
- At 8–12 sales/week (achievable from existing submit-page traffic), that's $1.2k–$1.8k/wk at >90% margin
- Leaves room for a $497 "Engineer-reviewed track" upsell later (that one *does* require your time, but it's optional and capacity-capped)
