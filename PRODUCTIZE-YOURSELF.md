## Winning Product Structure

### Name
**The OCD Release Protocol™ — From Hard Drive to Sync Cheque in 90 Days**
Proprietary mechanism: the **Sonic Architecture Map** — a reverse-engineered grid of sync-brief language (mood / tempo / texture / negative-space) mapped to concrete production checkpoints (BPM windows, sidechain depth, stereo field, stem labelling, LUFS target). No one else publishes this map because nobody else runs a label that vets to it.

### Contents
1. **Module 1 — The Obsession Audit.** Kill-list framework: which of your "finished" tracks will never license, and why. Done in 90 minutes with a printable scoring sheet.
2. **Module 2 — Sonic Architecture.** The full grid: 7 sync briefs × the production specs that match each. The proprietary core.
3. **Module 3 — The Neural Pass.** AI-assisted mastering + stem prep workflow (LANDR / Ozone / iZotope RX) tuned to the OCD chain.
4. **Module 4 — Release Mechanics.** ISRC, metadata, splits, sync registration, PRO walkthrough — the unsexy work that gates revenue.
5. **Module 5 — The Distribution Stack.** The 9 sync libraries to submit to, in what order, with the cold-email scripts that actually open doors.
6. **Template Kit (download).** Ableton + Logic session templates, master-chain presets, split-sheet PDFs, submission email scripts, metadata CSV template.
7. **Bonus — Monthly Catalog Review.** Group-format, recorded async, so it scales. Optional, not required to ship the course.

### Delivery (the "3am without me" mechanism)
- Hosted on Podia or Thinkific → auto-enrolls on Stripe purchase.
- Template kit delivered as ZIP via Gumroad-style auto-link.
- Onboarding + nurture sequence on ConvertKit / MailerLite — every lifecycle email pre-written.
- Support handled by a single Loom-recorded FAQ + a help@ inbox you triage once/week. **No live calls in the core product.**

### Price Point
**$497 one-time** (or 3 × $197).
Rationale: a single sync placement pays $1K–$10K+, so payback in one placement makes the offer obvious. $497 also filters for serious artists, matching the OCD brand's "obsession" positioning — too low and you attract dilettantes; too high and you lose the bedroom-producer beachhead.

### What makes it irreplaceable
The **Sonic Architecture Map** is proprietary because OCD Records is the source — graduates can submit directly to the actual label catalog at `submit.html`, with a flagged review path. No other course can credibly say "the same protocol our label A&Rs use." That implicit certification is the moat.
