## Winning Product: ENTROPY Catalog OS

### Name
**ENTROPY Catalog OS** — subtitle: *"The seven-step protocol OCD Records uses to turn raw stems into sync-licensable catalog."*

ENTROPY is both the acronym and the brand callback:

- **E**xtract — isolate masters, stems, and loops into a canonical folder structure
- **N**ame — apply the OCD naming taxonomy (artist · release code · BPM · key · mood)
- **T**ag — fill the 24-field sync metadata schema (ISRC, PRO, mood tags, scene archetypes, exclusivity flag)
- **R**egister — automated PRO + ISRC + content-ID submission checklist
- **O**ffer — tier the track (Standard / Premium / Enterprise) using the OCD pricing matrix
- **P**ublish — one-click export to DISCO / Songtradr / your own site's catalog JSON
- **Y**ield — the royalty-tracking dashboard view

### Contents
1. **ENTROPY Protocol one-pager** (PDF) — the full method on a single page a producer can print and tape above the desk.
2. **Airtable base** (duplicate link) — pre-populated with the 24 sync metadata fields, auto-generating release codes, a kanban view of each track's protocol stage, and a filtered "Ready-to-Pitch" view.
3. **Notion template** (duplicate link) — brief tracker, supervisor CRM, revenue ledger per track.
4. **File naming + folder structure template** (`.zip`) — mirrors the Airtable's expected inputs so the import never breaks.
5. **Sanitized Entropy-001 case study** — the exact Airtable record for the flagship release, warts and all, so buyers see the shape of a finished protocol run.
6. **Catalog JSON export schema + example** — matches the format the OCD Records `catalog.html` page already consumes, so power users can self-host a licensing storefront.
7. **Loom walkthrough** (one 25-minute recording) — the only video asset; records once, sells forever.
